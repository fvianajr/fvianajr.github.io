Projeto Ligy/Economy

Resumo: automação operacional para consultar pendências no banco, baixar faturas no portal Enel, usar Gmail no fluxo, registrar o processamento e organizar dados para cobrança, BigQuery e dashboards.

Contexto: a rotina reunia faturas, cobranças e indicadores em sistemas diferentes. A conferência manual consumia tempo e aumentava o risco de perder anexos, repetir processos ou trabalhar com informação desatualizada.

Uso: o fluxo consulta o banco, monta a fila de faturas pendentes, acessa o portal Enel, baixa e valida os arquivos, usa Gmail quando necessário e registra o resultado para acompanhamento operacional.

Ferramentas: Python para automação, SQL para consultas e modelagem, APIs para extração de tabelas, Gmail API para leitura/envio, Cloud Run para execução em nuvem e BigQuery para análise.

Python · SQL · Gmail API · APIs REST · SQLite · PostgreSQL · BigQuery · Cloud Run · BI

Como foi feito

Trechos simplificados e higienizados do fluxo. A ideia é mostrar a estrutura da solução sem expor clientes, credenciais, caminhos internos ou dados reais.

1. Banco monta a fila de faturas

SELECT
    instalacao,
    cliente_id,
    mes_referencia,
    status
FROM vw_faturas_pendentes
WHERE status IN ('disponivel', 'em_atraso')
  AND ja_processado = 0
ORDER BY mes_referencia, instalacao;

2. Automação executa cada item

for item in fila:
    resultado = baixar_fatura_enel(
        instalacao=item.instalacao,
        mes=item.mes_referencia
    )

    registrar_status(
        instalacao=item.instalacao,
        mes=item.mes_referencia,
        status=resultado.status
    )

3. Gmail entra no fluxo

mensagem = buscar_email_gmail(
    assunto="codigo de seguranca",
    recebido_apos=inicio_execucao
)

codigo = extrair_codigo(mensagem)
preencher_codigo_no_portal(codigo)

4. Dados seguem para análise

MERGE dataset.faturas AS destino
USING staging.faturas AS origem
ON destino.chave_fatura = origem.chave_fatura
WHEN MATCHED THEN UPDATE SET
    status = origem.status,
    atualizado_em = origem.atualizado_em
WHEN NOT MATCHED THEN INSERT ROW;
